# Lab syllabus map

This map follows the supplied Technical Writing Lab syllabus and its four units.

## Unit 1 — 8 hours
- Documentation using Google Docs and creating presentations
- Doxygen
- Graph plotting software, e.g. Python Matplotlib
- Drawing software, e.g. draw.io and OpenOffice
- LaTeX / Overleaf documentation
- Beamer: slides, frames, multiple columns, and blocks

## Unit 2 — 8 hours
- LaTeX introduction and installation
- First document
- Article and book classes
- Sections and document organisation
- Paper sizes and packages
- Margins, headers, and footers
- Multiple columns

## Unit 3 — 6 hours
- Text formatting: styles, size, alignment
- Complex mathematics
- Tables
- Simple and dashed borders
- Merging rows and columns

## Unit 4 — 6 hours
- Cross-referencing
- Bibliography and references
- Indexing

## Lab evidence

For each actual lab task, add the task sheet or problem statement when permitted, implementation files, screenshots or output, and a short explanation. Do not invent tasks to fill gaps; add them as they are assigned.
