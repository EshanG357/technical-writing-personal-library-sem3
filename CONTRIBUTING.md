# Maintaining this library

This is a personal academic knowledge repository. Use the following conventions to keep it consistent.

## File and folder naming

- Use lowercase names and hyphens: `page-formatting.md`.
- Keep related assets beside the topic or in a clearly named `assets/` folder.
- Prefer descriptive filenames over names such as `final2.md`.

## Documentation quality

- Explain ideas in your own words.
- Include tested examples for commands and code.
- Add screenshots when they clarify an outcome.
- Link related pages instead of duplicating long explanations.
- Cite books, websites, software documentation, and borrowed diagrams.
- Mark incomplete pages as work in progress rather than presenting them as complete.

## Suggested Git workflow

1. `git status`
2. `git add <files>`
3. `git commit -m "docs: add LaTeX page styling notes"`
4. `git push`

Use focused commits that describe one logical change.
