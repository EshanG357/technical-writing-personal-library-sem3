## Recording a lab exercise

Use the [lab report template](../templates/lab-report-template.md). Where relevant, include:
- The actual task statement and objective.
- Tools, packages and software versions used.
- Procedure and source files.
- Screenshots or other output evidence.
- Observations and a short conclusion.

Add tasks as they are assigned and completed. Do not invent assignment titles, results, screenshots or outputs to fill gaps.
