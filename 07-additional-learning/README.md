
# Additional Learning

This section documents technical topics, tools and concepts explored beyond the prescribed Technical Writing theory and laboratory syllabi.

It provides space to record independent learning that complements the coursework and contributes to broader technical understanding.

---

## What Belongs Here?

Examples of suitable material include:

- Additional documentation tools and workflows.
- Advanced LaTeX features beyond the prescribed syllabus.
- Extended Git and GitHub workflows.
- Other technical writing and visualisation tools.
- Independent experiments related to documentation and technical communication.

These are examples of possible topics, not a list of completed activities.

## Documentation Guidelines

Each additional topic should include, where applicable:

1. Topic overview and motivation.
2. Concepts and explanations.
3. Tools and technologies used.
4. Practical examples or experiments.
5. Source files and output evidence.
6. References and further learning resources.

Clearly distinguish independently explored material from prescribed and assessed coursework.

Only add topics that have actually been studied or practised.
