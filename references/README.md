## Referencing Guidelines

When using external material in this repository:

1. Give credit to the original author or organisation.
2. Prefer official documentation and primary sources.
3. Include the title and URL of the resource.
4. Include publication details for books and academic references.
5. Add an access date when documenting web resources where useful.
6. Cite external code, diagrams, images and other reproduced material appropriately.

The references listed here are learning resources. Cite the specific source used within the relevant chapter or practical report rather than assuming that listing a resource here automatically attributes every use.
