# Documentation Templates

This directory contains reusable templates for maintaining consistent documentation across the repository.

## Available Templates

### 1. Topic Documentation Template

[topic-template.md](topic-template.md)

Use this template when creating theory notes or documenting a technical topic.

It includes:
- Overview and learning objectives
- Key concepts and explanations
- Commands, syntax and workflows
- Practical examples
- Output and screenshots
- Troubleshooting
- References

### 2. Laboratory Report Template

[lab-report-template.md](lab-report-template.md)

Use this template for documenting assigned laboratory exercises and practical work.

It includes:
- Problem statement and objective
- Tools and requirements
- Theory and procedure
- Implementation and source files
- Output and evidence
- Observations and conclusion
- References

## Usage Guidelines

- Copy the appropriate template into the relevant section.
- Replace all placeholder content with actual information.
- Remove sections that are not relevant.
- Include source files and output evidence wherever applicable.
- Cite external resources appropriately.

These templates are starting points and can be adapted to suit individual topics and assignments.
