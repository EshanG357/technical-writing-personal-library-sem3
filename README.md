## Repository goals

## How each topic is documented

Topic pages aim to include:
1. Overview and learning objectives
2. Key concepts and terminology
3. Step-by-step explanation
4. Syntax, commands, or workflow where relevant
5. Practical example
6. Output or screenshots where useful
7. Common errors and troubleshooting
8. Summary and references

Not every section is necessary for every topic. Documentation should remain useful rather than padded.

## Lab documentation

Each lab record should include the problem or task, objective, tools used, procedure, source files, output evidence, observations, and conclusion where applicable.
