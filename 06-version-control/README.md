# Version control: Git, GitHub, and SVN

## Learning path
- [ ] Why version control is useful
- [ ] Git concepts: repository, working tree, staging area, commit
- [ ] Installation and configuration
- [ ] `git init`, `git status`, `git add`, `git commit`, `git log`
- [ ] Local and remote repositories
- [ ] GitHub repositories and remote setup
- [ ] `git clone`, `git push`, `git pull`, `git fetch`
- [ ] Branching and merging
- [ ] Merge conflicts and resolution
- [ ] `.gitignore`
- [ ] README and repository organisation
- [ ] SVN overview and comparison with Git

Use safe practice repositories for experiments. Never commit passwords, API keys, tokens, or private information.
