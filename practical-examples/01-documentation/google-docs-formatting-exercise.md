# Google Docs Formatting Exercise

This exercise demonstrates document creation, formatting, navigation and collaboration using Google Docs.

## Objective

Create a short technical document titled **Introduction to Computer Networks**.

## Procedure

1. Open [Google Docs](https://docs.google.com/) and create a blank document.
2. Add the title, author and date.
3. Create the following sections using built-in heading styles:
   - Introduction
   - Types of Networks
   - Network Topologies
   - Applications
   - Conclusion
4. Apply Heading 1 to section headings and Heading 2 to suitable subsections.
5. Insert a table comparing LAN, MAN and WAN.
6. Insert a numbered list describing the steps in data transmission.
7. Add a relevant diagram using Insert → Drawing, or insert an image with an appropriate caption.
8. Insert a table of contents using Insert → Table of contents.
9. Add a comment to a paragraph and try Suggesting mode.
10. Use Share to give a collaborator Viewer, Commenter or Editor access as appropriate.
11. Open version history to inspect document changes.
12. Download the finished document as a PDF.

## Expected Result

A consistently formatted technical document containing:

- A title and structured headings.
- A table of contents.
- A comparison table.
- A numbered list.
- A diagram or illustration.
- A comment or suggestion.
- A PDF export.

## Evidence to Keep

Save a PDF export and screenshots showing the document structure, table of contents, collaboration/comment feature and final output. Do not share documents publicly if they contain private information.

## Observation

Briefly note which formatting and collaboration features were used and how they improve technical communication.
