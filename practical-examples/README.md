# Practical Examples

This directory contains small, reproducible demonstrations of the major tools and concepts covered in Technical Writing and Technical Writing Laboratory.

Each example includes source files and instructions. Committed sample outputs are included where useful; temporary build files such as Doxygen HTML folders and compiler intermediates can be recreated locally.

## Examples

| Area | Demonstration | Source |
|---|---|---|
| Documentation | Google Docs formatting and Doxygen calculator | [01-documentation](01-documentation/) |
| LaTeX | Formatted technical report | [02-latex](02-latex/) |
| Git and GitHub | Feature-branch workflow and SVN command reference | [03-git-and-github](03-git-and-github/) |
| Drawing and graphics | Flowchart, GNUPlot and Matplotlib plots | [04-drawing-and-graphics](04-drawing-and-graphics/) |
| Beamer | Short slide presentation | [05-beamer](05-beamer/) |

## How to Use

1. Open the relevant example directory.
2. Read its README for prerequisites and commands.
3. Run or compile the source files.
4. Compare the generated result with the committed output where provided.
5. Keep temporary build files local unless there is a clear reason to publish them.

These are learning demonstrations, not substitutes for assigned laboratory submissions.

## Scope

Examples are intentionally small and focused. They demonstrate core workflows without introducing unnecessary project complexity.
