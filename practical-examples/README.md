# Practical Examples

This directory contains small, reproducible demonstrations of the major tools and concepts covered in Technical Writing and Technical Writing Laboratory.

Each example should include its source files, brief instructions, and generated output or screenshots where appropriate.

## Examples

| Area | Demonstration | Files |
|---|---|---|
| Documentation | Generate API documentation with Doxygen | [01-documentation/doxygen-calculator](01-documentation/doxygen-calculator/) |
| LaTeX | Compile a formatted technical report | [02-latex](02-latex/) |
| Git and GitHub | Practise a feature-branch workflow | [03-git-and-github](03-git-and-github/) |
| Drawing and graphics | Create a flowchart and plot functions | [04-drawing-and-graphics](04-drawing-and-graphics/) |
| Beamer | Build a short slide presentation | [05-beamer](05-beamer/) |

## How to Use

1. Open the relevant example directory.
2. Read its README for prerequisites and commands.
3. Run or compile the source files.
4. Compare the generated output with the expected result.
5. Keep screenshots or generated files alongside the source when useful.

These are learning demonstrations, not substitutes for assigned laboratory submissions. Add actual lab work separately under [06-lab-work](../06-lab-work/).

## Scope

Examples are intentionally small and focused. They demonstrate core workflows without introducing unnecessary project complexity.
